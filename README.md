# SmartWallet App

Ứng dụng di động trên nền tảng Android hỗ trợ quản lý tài chính cá nhân, giúp người dùng theo dõi và kiểm soát chi tiêu thông minh.

## Tính năng chính
* **Quản lý giao dịch:** Ghi chép và theo dõi các khoản thu/chi hàng ngày.
* **Phân loại danh mục:** Tổ chức các khoản chi tiêu theo từng nhóm danh mục cụ thể.
* **Báo cáo & Thống kê:** Cung cấp biểu đồ trực quan và báo cáo tổng hợp chi tiết theo thời gian.

## Công nghệ sử dụng
* **Môi trường phát triển:** Android Studio
* **Ngôn ngữ/Cấu trúc:** Java, XML
* **Công cụ quản lý thư viện:** Gradle
